# Invoice Management App

A React invoice management app with create, edit, delete, draft saving, pending-to-paid workflow, filtering, responsive layout, and dark mode persistence.

## Run locally

```bash
npm install
npm run dev
```

## Features

- Create, view, update, and delete invoices
- Save as draft
- Save & Send creates a pending invoice
- Mark pending invoices as paid
- Filter by draft, pending, and paid
- Light/dark mode stored in localStorage
- Responsive design
- Accessible modal and form labels
